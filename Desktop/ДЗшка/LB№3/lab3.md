# Звіт до лабораторної роботи №3

**Тема:** Робота з умовами в розмітці. Застосування конструкцій `if-else` для зміни візуального оформлення елементів сторінки.

## Фрагмент коду з умовами в розмітці та тернарним оператором

```php
<li class="task-item <?= $isCompleted ? 'task-done' : 'task-pending' ?>">
    <span><?= htmlspecialchars($taskTitle) ?></span>

    <?php if ($isCompleted): ?>
        <span class="status-badge">✔️ Виконано</span>
    <?php else: ?>
        <span class="status-badge">🕒 В процесі</span>
    <?php endif; ?>
</li>
```

---

## Контрольні запитання

### 1. Які оператори порівняння існують у PHP (назвіть мінімум 4)?
У PHP доступні такі оператори порівняння:
* `==` — нестроге порівняння на рівність (з приведенням типів).
* `===` — строге (тотожне) порівняння на рівність (перевіряє одночасно і значення, і тип даних).
* `!=` або `<>` — нестроге порівняння «не дорівнює».
* `<`, `>`, `<=`, `>=` — оператори «менше», «більше», «менше або дорівнює», «більше або дорівнює».
* `<=>` — оператор тристороннього порівняння (*spaceship operator*), який повертає `-1`, `0` або `1` залежно від того, чи лівий операнд менший, рівний або більший за правий.

### 2. У чому різниця між тотожним порівнянням (`===`) та звичайним прирівнюванням (`==`) у PHP? Наведіть приклад, де результати відрізнятимуться.
Звичайне прирівнювання (`==`) перед порівнянням виконує автоматичне приведення типів (*type juggling*), тому різні за типом дані можуть вважатися рівними. Тотожне порівняння (`===`) не перетворює типи автоматично й повертає `true` лише тоді, коли збігаються **і значення, і тип даних**.

**Приклад:**
```php
var_dump("10" == 10);  // bool(true) — рядок "10" приводиться до числа 10
var_dump("10" === 10); // bool(false) — різні типи: string та int
```

### 3. Для чого потрібен альтернативний синтаксис керуючих конструкцій (`if (...): … endif;`) під час роботи з HTML?
Альтернативний синтаксис (`if ...: ... endif;`, `foreach ...: ... endforeach;`, `while ...: ... endwhile;`, `for ...: ... endfor;`) створений спеціально для шаблонів, де PHP чергується з великою кількістю HTML-розмітки. Замість безлічі фігурних дужок `}`, за якими легко заплутатися, що саме закривається, з'являються явні ключові слова завершення блоку (`endif;`, `endforeach;` тощо). Це робить розмітку читабельнішою та зменшує ризик синтаксичних помилок.

### 4. Що таке тернарний оператор і який він має синтаксис? Коли його використання є недоцільним?
Тернарний оператор — це компактна умовна конструкція, яка обирає одне з двох значень залежно від умови.

**Синтаксис:**
```php
$результат = умова ? значення_якщо_true : значення_якщо_false;
```
(Також існує скорочена форма `?:`, коли при істинності повертається сам лівий вираз.)

Використовувати тернарний оператор **недоцільно**, коли умова складна або багатоступенева, коли є вкладені тернарні оператори (це сильно ускладнює читання), або коли всередині гілок потрібна складна логіка чи кілька інструкцій — у таких випадках краще обрати звичайний `if / elseif / else`.

### 5. Які значення в PHP приводяться до `false` при перетворенні типів (type juggling) в умові `if`?
При неявному перетворенні до булевого типу (`bool`) в умові `if` до `false` приводяться:
* саме значення `false`;
* цілі нулі: `0` та `-0`;
* числа з рухомою комою: `0.0` та `-0.0`;
* порожній рядок `""` та рядок `"0"` (при цьому рядки на кшталт `"false"` або `"0.0"` у логічному контексті дають `true`);
* порожній масив `[]`;
* значення `null` (а також неініціалізовані або невизначені змінні, які трактуються як `null`);
* порожні об'єкти `SimpleXML`, створені з порожніх тегів.
